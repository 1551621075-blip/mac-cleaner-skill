## TDD 与实际结果

运行环境：macOS Darwin 22.3.0，Python 3.12.0，标准库 unittest。运行时使用源码外 cwd、独立合成 HOME、`-I -B`，临时树路径先 `resolve()` 为 `/private/var/...`。运行日志在源码外新建的 mode 0700 私有目录中以 0600 保存，不作为发布文件。

1. **静态 RED**：原复制件只由 AST 读取，4 项测试按预期失败：无 `main(argv)`、无 main guard、无 argparse、隐式 home。没有执行/import 原版，也没有读取其历史固定报告文件。
2. **合成合同先行**：先写六类规则、安全输出和故障测试，导入安全门禁使原版测试失败而不执行模块。
3. **修复迭代**：首次运行暴露 macOS AF_UNIX 路径长度测试夹具问题，改为仅在自建目录绑定短相对路径；另补根权限失败、重复组排序及已固定根重命名回归。最后一项先复现 `not_present` 错误，再改为 `partial`。
4. **完整 GREEN**：43 项通过，unittest 报告耗时 **0.943 秒**；连同子进程驱动约 **1.072 秒**。含独立静态复核指出的显式 `--output ''` 回归：先复现错误退出 0，再修复为扫描前拒绝退出 2。这是该小合成集的实际耗时，不是实际用户目录扫描耗时承诺。

### 覆盖内容

- 六类规则：六个人目录/Library 固定范围、固定文件和目录名、逻辑大小与时间的严格/非严格阈值、UTC 秒比较、排序、Top 截断前数量与小计。
- 嵌套系统目录去重、部分目录已知小计、缓存阈值未知、旧下载目录 `size=null` 不纳入字节、一层旧下载、缺根 `not_present`。
- 默认 `not_run`，元信息模式不打开普通文件正文、不调用 `os.read`、不枚举无关根；查重 SHA-256 相同/不同、阈值、硬链接排除、Top 20 组。
- 权限/stat/listdir/open/read 故障注入；哈希 inode/size/mtime 变化及打开后普通文件校验；变化记未知/partial。
- 合成 file/dir/broken/intermediate/root symlink；FIFO、AF_UNIX socket；device 使用元信息注入，不创建真实设备。文件被替换为 symlink/FIFO、目录交换、扫描根和输出父目录重命名。
- 相对路径及控制字符 JSON 转义、异常不回显绝对路径；无“可释放”估计。
- main guard 导入无输出/扫描/写文件，真实子进程 `--help`/缺参；100 MiB 自建稀疏文件恰好命中 CLI 大文件边界，真实 CLI JSON 0600。
- 输出预检、扫描根内拒绝、独占新建、不覆盖现有文件或链接、拒中间链接/非私有/缺失父目录、扫描后目标出现竞态、写失败保留本次不完整新文件、退出码 0/1/2。

常规合成扫描前后比较文件内容摘要、inode、mode、size、mtime 及目录项，未出现删除/内容修改；不比较 atime，允许读取造成访问时间更新。专门的重命名/替换测试由测试夹具主动改动后恢复，不将这种主动扰动伪称为输入始终未变。扫描代码没有删除调用。

测试进程封禁 socket connect/connect_ex/sendto/create_connection；CLI 源码另经 AST 导入白名单检查，不包含网络或外部进程模块。CLI 子进程为 `-I -B` 且 HOME/cwd 独立合成目录。不将这些限制称为 OS 网络沙箱。

## 明确未测、不能推导的结论

- **宿主 Skill 真实模型效果未测**，未执行模型压力场景、未验证所有技能客户端的发现/安装/授权交互。SKILL 的检查是静态契约检查，不是实际宿主遵循性成绩。
- 未扫描真实家目录、浏览器数据库或凭据；不据合成测试对当前机器问题或磁盘收益作判断。
- 未验证所有 ACL、APFS 克隆/压缩/物理回收量、其他 OS/网络文件系统、规模性能、所有并发交换时序、资源极限。
- FD 固定和逐组件 `O_NOFOLLOW`、前后身份检查能限制重定向，但不构成原子快照或 OS 沙箱。父目录若在最后核对与创建之间被移动，可能在旧 FD 指向的目录留下本次新建空/不完整文件；已有回归检查失败退出、不删除，而不是承诺这种竞态绝不发生。
- 权限检查基于 POSIX owner/mode，不声明完整 ACL 审计。哈希匹配只表示疑似重复，不能据此直接删除。
- 精确清单及常见敏感字符串检查不是完整秘密审计或全局安全证明。未进行安装、Git 初始化、提交、推送或公开发布。
